# 途中画册：跳转页面设计稿

运行 `node docs/redirect-gallery/serve.mjs`，打开 `http://localhost:3174/?review=1`。

这是独立的可交互设计稿，尚未修改正式 Go 跳转页。预览默认暂停，方便查看；右下「预览选项」可查看六幅作品和重新演示 2 / 5 / 10 秒倒计时。预览控件只在 `review=1` 时出现。普通入口每次随机展示一幅作品，默认 2 秒后抵达本地 `destination.html` 演示终点。

## 设计

- 暖黑展墙、浅色装裱，作品占主要空间；横幅与竖幅均保持完整比例。
- 作品旁显示标题、作者、年代、两句画面介绍和原作资料；注明这是名画的像素演绎。
- 底部固定信息层级：最终目标域名、可展开的完整地址、倒计时、停留欣赏、立即前往。桌面是一条窄栏，手机用两行紧凑底栏。
- 「停留欣赏」真正停止计时，「继续倒计时」从剩余时间继续；不会轮换作品。
- 每次进入仅随机选一幅并请求该 SVG。六个 fine SVG 原样复制自用户提供的 viewer.html 配套目录。
- `?review=1&lang=en` 查看英文；`?mode=preview` 演示短链接 `+` 预览模式，不自动离开。

## 接入正式页面时保留的行为

1. 保持原链接配置的倒计时时长（当前默认 2 秒，支持 0–60 秒），不为画册延长时间。
2. Go 服务端每请求随机选一幅，嵌入可信 SVG 和对应语言文案；不要把整套图库随页发送。
3. 以 JavaScript 的真实计时取代当前全局 meta refresh，暂停必须阻止实际导航。无脚本环境可在 noscript 中保留原有倒计时跳转及手动链接。
4. 普通访问沿用现有计数，`+` 预览不计数、不自动跳转。暂停、恢复不访问短码接口，不增加点击。
5. 目标域名、完整地址和 CTA 来自同一个经设备规则与查询参数合并后的目标。继续转义动态文字与链接。
6. 保留语言协商、no-store、noindex/nofollow、HEAD 无正文及不计点击；静态画作、键盘焦点、图片替代文字和 reduced-motion。

预览中展示故宫网站地址作为排版示例，所有跳转交互均进入本地演示终点。正式接入时替换为真实目标。

## 验证

浏览器交互检查 47 项通过：2 秒自动跳转、暂停后停留、从剩余时间恢复、立即前往、无倒计时预览、每次仅加载一张 SVG，以及六幅作品在桌面 1440px、手机 390px、英文 320px 的布局。额外验证完整地址展开与 Escape 关闭、手机滚动到底后正文不被底栏遮住。英文最窄预览工具曾与页头重叠，已调整字距并复验。
